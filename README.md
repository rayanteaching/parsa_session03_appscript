# Parsa Session 03 — Python for Teens

Repository for Session 03 of Parsa's Python practice portal.

Focus: `for`, `range()`, looping over lists, and a simple combination of `for` with `if`.

Repository workflow:
- `main` is the trusted baseline.
- Development happens only on `task/*`, `fix/*`, or `harness/*` branches.
- Changes reach `main` through review and verification.

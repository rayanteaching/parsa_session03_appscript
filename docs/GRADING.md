# Manual Grading Policy — Session 03

## Score structure

Authoritative maxima come from `Config.gs`. The intended Session 03 structure is MCQ + Code Repair + Final Coding = Total.

## Code Repair

Four repair tasks are graded manually. The default rubric is 5 points per task:

- 5: correct repair and intended behavior;
- 3–4: core idea is correct but a minor requested detail is wrong;
- 1–2: partial understanding with substantial correction still needed;
- 0: no meaningful solution.

## Final Coding rubric

Use the task-specific requirements, with attention to:

1. correct `for` structure and indentation;
2. correct iteration target (`range` or list item as requested);
3. correct `if` condition when present, especially inclusive boundaries such as `>=`;
4. exact requested output text/case and compliance with stated constraints.

## Privacy boundary

Student-specific scores, submitted code, submission IDs, names, emails, and private feedback belong in the Results Spreadsheet and must never be committed to this public repository.
